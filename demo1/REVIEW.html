Re-proposal: Signal Minimal

IT Design desk · Response to “r1 looks uglier” · 2026-07-29

We heard you.

r1 piled on grain, heavy paper chrome, and busy chips. That is not premium. r2 removes decoration and ships a dark, minimal, futuristic system with pure CSS motion only.

Open visual demo →

What changed vs r1

r1 (rejected)r2 (this)
Warm paper + noise grainDeep black canvas, no texture
Heavy shadows / brown goldHairline borders, single accent gold
Chips on every imageOne label line; accent bar on hover
JS for category filterRadios + :has() · zero JS
Motion noiseOpacity/transform only · reduced-motion safe

Engineering bar

  • Pure CSS animations (compositor: transform + opacity)
  • Category filter with native radios and :has() — no script dependency
  • System UI font for chrome; one display face for titles only
  • color-mix, min(), sticky + backdrop-filter
  • prefers-reduced-motion, :focus-visible, icon aria-label
  • No animation libraries, no framework

North star

Flagship-product restraint (Linear / Vercel / Arc class) applied to a cultural chronicle. Futuristic without neon. Every pixel earns its place.

Feedback we need

  • Is dark premium the right default for CoC, or light-only?
  • Accent gold #c9a227 — keep, cooler, or pure white/silver?
  • Card density: this spacing vs tighter?
  • Greenlight r2 direction over live + r1?
